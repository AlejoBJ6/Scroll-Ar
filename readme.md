# Proyecto: Blog con Bootstrap

## Descripción del Proyecto
Este proyecto grupal consiste en el diseño y maquetación de un blog temático. El sitio ha sido desarrollado garantizando que sea completamente responsive, priorizando una estructura de proyecto organizada y un código limpio. El proyecto pertenece al equipo 4 del trabajo de fin de modulo.

## Características Principales
El blog cuenta con las siguientes vistas y componentes:

* **Navegación Global:** Un navbar fijo en la parte superior que incluye accesos a Login, Contacto, Acerca de nosotros y un botón de suscripción que activa un formulario modal.
* **Footer Responsive:** Pie de página con información del sitio y redes sociales, que se adapta mostrando desde una hasta tres columnas dependiendo del dispositivo.
* **Página Principal (Home):** Cuenta con un slider principal, un listado con las últimas entradas (imagen, título, descripción y botón "ver más") y su respectiva paginación. Incluye una barra lateral con buscador, categorías y publicidad.
* **Detalle de Entrada:** Vista dedicada para la lectura de artículos con soporte para imágenes/videos, e incluye una sección al final con un formulario para comentar y una previsualización de comentarios existentes.
* **Galería de Imágenes:** Grid visual que se adapta de 1 columna en móviles a 4 columnas en pantallas grandes.
* **Login y Autenticación:** Pantalla dividida para iniciar sesión (incluyendo opciones de Google/Facebook) y un enlace para recuperar la contraseña mediante un modal.
* **Contacto:** Formulario de consultas acompañado de un mapa con la ubicación.
* **Acerca de Nosotros:** Sección dedicada a presentar al equipo de desarrollo con una galería de avatares circulares.
* **Error 404:** Página de resguardo para enlaces sin funcionalidad establecida.

## Tecnologías Utilizadas
* HTML5
* CSS3
* Bootstrap (Framework CSS)
